# TI profile notes

The included `iwr6843_example.cfg` is an **example starting point**, not a universal profile.

TI CLI commands and output TLV formats depend on:
- EVM type
- flashed firmware/demo
- mmWave SDK generation
- chirp profile

For a real deployment, generate and validate a profile that matches the exact firmware running on your IWR6843 board. Record the firmware version and configuration in your release notes.
